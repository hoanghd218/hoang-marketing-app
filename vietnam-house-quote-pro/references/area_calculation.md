# Cách Tính Diện Tích Xây Dựng (Hệ Số Hao Phí)

Trong xây dựng nhà dân dụng tại Việt Nam, diện tích tính giá không chỉ là diện tích sàn sử dụng mà còn bao gồm các phần hao phí xây dựng khác.

## 1. Công Thức Tổng Quát
**Tổng diện tích xây dựng (DTXD) = Σ (Diện tích hạng mục × Hệ số %)**

## 2. Bảng Hệ Số Tính Diện Tích Phổ Biến

| Hạng Mục | Hệ Số Tính (%) | Ghi Chú |
| :--- | :--- | :--- |
| **Móng Băng** | 50% - 60% | Tính trên diện tích tầng trệt |
| **Móng Cọc** | 40% - 50% | Chưa bao gồm chi phí ép cọc |
| **Móng Bè** | 100% | Tính trên diện tích tầng trệt |
| **Tầng Hầm** | 150% - 250% | Tùy độ sâu (Sâu < 1.5m tính 150%, > 2m tính 250%) |
| **Tầng Trệt / Lầu** | 100% | Diện tích có mái che |
| **Thông Tầng / Ban Công**| 100% | Tính như diện tích sàn |
| **Sân Thượng Có Mái** | 70% - 80% | Phần có mái che và khung trang trí |
| **Sân Thượng Không Mái**| 50% | Phần sân trống |
| **Mái Tôn** | 30% | Tính theo độ nghiêng (thường tính 30% diện tích sàn) |
| **Mái Ngói (Kèo Sắt)** | 70% | Tính theo diện tích mặt nghiêng |
| **Mái Bê Tông Cốt Thép**| 50% | Mái bằng BTCT |
| **Sân Trước / Sau** | 50% - 70% | Tùy vào mức độ gia cố móng sân |

## 3. Ví Dụ Minh Họa
**Nhà phố 1 trệt 2 lầu, mái BTCT, móng băng, diện tích sàn 50m2 (5x10):**
1. Móng băng: 50m2 × 50% = 25m2
2. Tầng trệt: 50m2 × 100% = 50m2
3. Lầu 1: 50m2 × 100% = 50m2
4. Lầu 2: 50m2 × 100% = 50m2
5. Mái BTCT: 50m2 × 50% = 25m2
**=> Tổng DTXD = 25 + 50 + 50 + 50 + 25 = 200m2**
